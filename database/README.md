# 🗄️ Database Folder

This folder contains all database-related files and configurations for the InstaSell platform.

## 📁 Structure

```
database/
├── 📄 README.md                   # This file
├── 📄 db.ts                       # Database connection setup
├── 📁 prisma/                     # Prisma ORM files
│   ├── 📄 schema.prisma           # Database schema
│   └── 📁 migrations/             # Database migrations
├── 📁 migrations/                 # Migration files
├── 📁 seeds/                      # Database seed data
├── 📁 backups/                    # Database backups
├── 📄 setup-db.sh                 # Database setup script
├── 📄 setup-database.sh           # Database initialization
└── 📄 run-migrations-safe.sh     # Safe migration runner
```

## 🚀 Database Commands

### Setup Database
```bash
cd database
./setup-database.sh
```

### Run Migrations
```bash
cd database
./run-migrations-safe.sh
```

### Seed Database
```bash
cd database
npm run seed
```

### Generate Prisma Client
```bash
cd database
npx prisma generate
```

## 🗂️ Database Types

- **PostgreSQL**: Primary database
- **Redis**: Caching and session storage
- **Prisma ORM**: Database management

## 📋 Important Notes

- All database schema changes go in `prisma/schema.prisma`
- Migration files are auto-generated by Prisma
- Seed data is in `seeds/` folder
- Backups are stored in `backups/` folder
- Environment variables for database are in `shared/config/`

## 🔗 Related Files

- Backend API: `../backend/src/`
- Environment configs: `../shared/config/.env*`
- Deployment configs: `../deployment/`
